# BSERC Object Detection using YOLO11n

## Project Overview

This project presents an object detection system developed as part of the BSERC project using the YOLO11n architecture. The work covers the complete object detection pipeline, including dataset preparation, model training, validation, performance evaluation, and final testing.

The project focuses on developing and evaluating a YOLO11n-based model for detecting space debries in images.

---

## Objectives

- Develop an object detection model using YOLO11n.
- Prepare and validate the dataset for YOLO-based training.
- Train and validate the detection model.
- Evaluate model performance using standard detection metrics.
- Analyze model behavior using confidence and precision-recall curves.
- Perform final testing on unseen/test data.
- Document the complete methodology, results, and findings.

---

## Methodology

The project follows the workflow below:

1. Dataset Collection
2. Dataset Preparation and Annotation
3. Dataset Validation
4. YOLO11n Model Configuration
5. Model Training
6. Validation
7. Performance Evaluation
8. Final Testing
9. Result Visualization and Analysis
10. Documentation

## Results

The trained model was evaluated using standard object detection metrics.

### Final Performance

| Metric | Result |
|---|---:|
| Precision | **[0.808]** |
| Recall | **[0.683]** |
| mAP@50 | **[0.760]** |
| mAP@50–95 | **[0.520]** |
| F1 Score | **[0.84]** |

> The values above correspond to the final evaluation of the trained YOLO11n model on the selected evaluation/test dataset.
